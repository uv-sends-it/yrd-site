# Adding a newsletter (no Git experience needed)

1. Get the newsletter file (PDF, or a webpage saved as HTML).
2. Rename it to `YYYY-MM-newsletter.pdf` — for example, the March 2026 issue is
   `2026-03-newsletter.pdf`. Use `.html` instead of `.pdf` if it's a webpage.
3. Open this project on GitHub in your browser, go into the `content/newsletters/` folder.
4. Click "Add file" → "Upload files", then drag your renamed file in.
5. Scroll down and click "Commit changes" (the green button). That's it — the website
   rebuilds itself and the new issue shows up on the Newsletter page within a couple of
   minutes.

Nothing else needs to change. The site automatically lists newsletters newest-first,
grouped by year, based on the filename.
